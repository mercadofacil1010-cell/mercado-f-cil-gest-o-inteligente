# Mercado Fácil: Gestão Inteligente

Crie agora a primeira versão visual de um sistema SaaS profissional chamado “Mercado Fácil”, destinado ao gerenciamento de redes de supermercados.

IMPORTANTE: não responda somente com explicações ou planejamento. Crie e exiba imediatamente uma interface funcional na tela de visualização.

Nesta primeira etapa, crie:

1. Identidade visual completa.

2. Logo original do Mercado Fácil.

3. Menu e estrutura principal do sistema.

4. Tela de login pronta e visível.

5. Tela de apresentação inicial do sistema.

6. Versões responsivas para computador, tablet e celular.

IDENTIDADE VISUAL:

Quero aparência de software empresarial de grande porte, moderno, confiável e fácil de usar.

Use como cores principais:

- Azul-marinho escuro: #0B1F33

- Turquesa: #00B8A9

- Verde-lima para destaques: #A3E635

- Fundo claro: #F5F7FA

- Branco para cards: #FFFFFF

- Cinza para textos secundários: #64748B

- Vermelho somente para alertas críticos: #EF4444

- Amarelo somente para atenção: #F59E0B

A interface não deve parecer infantil, genérica ou excessivamente colorida.

LOGO:

Crie um logo original para “Mercado Fácil”. O símbolo deve combinar de maneira elegante:

- A letra M;

- Uma gôndola ou prateleira;

- Uma caixa ou produto;

- Sensação de organização, tecnologia e controle.

Produza o símbolo em SVG ou componente reutilizável, acompanhado do nome “Mercado Fácil”. Crie versões para fundo claro e fundo escuro.

TEMA VISUAL:

- Cantos moderadamente arredondados.

- Sombras suaves.

- Ícones modernos e consistentes.

- Tipografia forte, limpa e de fácil leitura.

- Botões com estados normal, hover, pressionado e desabilitado.

- Cards elegantes.

- Boa separação entre informações.

- Acessibilidade e bom contraste.

- Não utilizar textos pequenos.

TELA DE LOGIN:

Crie uma tela dividida em duas áreas.

No lado esquerdo, mostre o logo, uma apresentação do sistema e uma ilustração visual relacionada a estoque, supermercado, depósito e gôndolas.

Texto principal:

“Controle todos os seus mercados em um só lugar.”

Texto secundário:

“Estoque, recebimento, reposição, validade e vendas acompanhados em tempo real.”

No lado direito, crie o formulário com:

- E-mail;

- Senha;

- Mostrar ou ocultar senha;

- Lembrar acesso;

- Esqueci minha senha;

- Botão “Entrar”;

- Botão “Continuar com Google”;

- Botão “Continuar com Facebook”;

- Link “Criar minha conta”;

- Selo “Teste grátis disponível”.

Inclua também uma opção discreta chamada “Acesso administrativo”, destinada ao proprietário da plataforma.

Ao clicar em “Entrar” usando os dados fictícios, encaminhe para uma dashboard provisória simples, apenas para demonstrar a navegação.

Não conecte banco de dados, Supabase, pagamento ou autenticação real. Use dados fictícios nesta fase.

Crie componentes reutilizáveis e mantenha a estrutura do código organizada. Todas as próximas telas deverão seguir exatamente essa identidade visual.
